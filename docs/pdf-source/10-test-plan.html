Entry criteria

The code compiles (tsc, next build, hardhat compile), dependencies are installed, and the environment is configured.

Exit criteria (release)

  • All automated tests pass; contract line coverage is 100%.
  • No open defects of severity High or Critical.
  • All PRD acceptance criteria pass on the deployed site (section 6).
  • npm audit --omit=dev reports no high or critical vulnerabilities.

Environments

Local testHardhat chain (31337), PostgreSQL 17, API, indexer, website production build on Windows 11, Node 25
Staging / livePolygon Amoy (80002), Supabase, Pinata, Docker; to be run before handover (see section 7)
